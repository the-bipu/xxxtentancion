## ✦ About This Space

This isn't just a repository — it's a memory box.

Built to hold onto the story, the journey, and the music of an artist whose sound and honesty left a mark that hasn't faded. This project archives his songs, moments, and the impact he had, kept here so it's never lost, never forgotten.

Rest easy, X. 🕊️

<br/>

## ✦ The Journey

Born in Plantation, Florida, Jahseh Onfroy — known to the world as **XXXTentacion** — rose from SoundCloud into one of the most talked-about and genre-bending voices in hip-hop. Raw, unfiltered, and often deeply emotional, his music refused to stay in one lane — bouncing between trap, emo-rap, punk, and R&B, often within the same project.

Albums and mixtapes like ***17***, ***?***, and ***Skins*** carried a rare kind of honesty — songs that sat with pain, mental health, love, and anger without flinching. That honesty is a big part of why his music still resonates the way it does.

He was gone far too soon, on June 18, 2018, at just 20 years old. What he left behind continues to reach people who needed to hear it.

<br/>

## ✦ Running This Locally

```bash
git clone https://github.com/the-bipu/xxxtentancion.git
cd xxxtentancion
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm start
```
